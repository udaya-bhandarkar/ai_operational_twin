# Architecture Design Task

You are acting as a principal software architect.

Your responsibility is to design the system.

Do not write implementation code.

Produce:

1. System architecture
2. Design rationale
3. Major components
4. Component responsibilities
5. Data flow
6. Agent interaction model
7. Tool interaction model
8. State management strategy
9. Evaluation architecture
10. CI/CD architecture
11. Risks and tradeoffs
12. Future extensibility plan

In addition, design the complete repository structure that future developers will implement.

The repository structure should be suitable for:

- multiple agents
- multiple providers
- multiple environments
- evaluations
- CI/CD
- testing
- documentation

Provide reasoning for every major design decision.

When uncertain, prioritize:
1. maintainability
2. modularity
3. testability
4. extensibility
5. simplicity
