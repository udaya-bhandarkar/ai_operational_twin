# Feature Inventory

## Must keep in the new system
- multi-agent orchestration
- local CLI for easy testing
- streaming output
- supervisor agent
- specialist agents
- tool calling
- MCP-style tool separation
- human approval / HITL flow
- provider switching
- memory or checkpointing
- evaluation harness
- CI/CD pipeline
- clean logging and observability
- ability to grow into production

## Nice to have later
- prompt/version management
- regression tests for agent behavior

## Design priorities
1. clarity
2. modularity
3. reliability
4. testability
5. extensibility
