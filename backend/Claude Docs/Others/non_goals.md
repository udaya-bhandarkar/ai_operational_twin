# Non Goals

The following are intentionally out of scope.

## Current Phase

- Writing implementation code.
- Building production infrastructure.
- Selecting exact frameworks.
- Optimizing performance.
- Fine-tuning models.

## Product Scope

- Autonomous AGI systems.
- Self-modifying agents.
- Fully autonomous execution without approval controls.
- Complex multi-region deployment.
- Multi-tenant SaaS architecture.

## Technical Scope

- Premature microservices.
- Premature Kubernetes design.
- Premature distributed systems design.
- Vendor-specific lock-in.
- Architecture decisions based solely on current implementation convenience.

## Documentation Scope

- API specifications.
- Detailed class diagrams.
- Detailed implementation plans.

These can be produced later after architecture approval.
